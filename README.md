# Grade Clicker

Интерактивный кликер оценок по курсу "Разработка мобильных приложений" - приложение на Android с Jetpack Compose

## Цель работы

Изучить жизненный цикл Activity в Android и научиться правильно обрабатывать переходы между состояниями - от onCreate до onDestroy, а также разобраться с сохранением состояния при изменении конфигурации устройства через rememberSaveable

## Контрольные вопросы

**Какие три метода вызываются при запуске приложения?**
onCreate, onStart, onResume - именно в таком порядке

**Чем отличается onPause() от onStop()?**
onPause вызывается когда Activity теряет фокус но ещё видна (например диалог поверх), onStop - когда Activity полностью уходит с экрана и становится невидимой

**Когда вызывается onRestart()?**
Когда Activity возвращается после onStop - то есть была в фоне и пользователь вернулся в приложение через Recent Apps

**Что происходит при повороте экрана?**
Android полностью уничтожает Activity (вызывается onDestroy) и создаёт её заново (onCreate) - это называется configuration change

**В чём разница между remember и rememberSaveable?**
remember сохраняет значение только при рекомпозиции, а rememberSaveable ещё и при configuration changes (поворот экрана, смена языка) - данные не теряются при пересоздании Activity

**Почему onCreate() должен вызывать super.onCreate()?**
Потому что родительский класс ComponentActivity делает обязательную инициализацию - без вызова super приложение упадёт с ошибкой

**Для чего используется класс Log?**
Для вывода сообщений в Logcat - позволяет отслеживать какие методы жизненного цикла вызываются и в каком порядке, очень помогает при отладке

**Какой метод вызывается только один раз за время жизни Activity?**
onCreate - вызывается только при первом создании Activity, при перезапуске после Stop вызывается onRestart, а не onCreate
